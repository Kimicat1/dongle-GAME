# dongle-lighthouse
My dongle is a lighthouse. There are LEDs that recreate the light of a lighthouse. I came up with that idea because a lighthouse fits perfectly to the idea of using just LEDs for this project, I had right at the beginning. Also my little lighthouse should bring joy, like a real lighthouse only brings gives you good feelings.
